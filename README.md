# MemeStream 

MemeStream은 유튜브, 틱톡 등 전 세계 최신 밈을 한곳에 모아 가장 빠르게 즐기는 실시간 밈 피드 앱.

## 주요 서비스 기능
① 메인 피드 (Main Feed)
* 실시간 밈 수집: 유튜브 쇼츠, 틱톡 등 다양한 플랫폼의 인기 밈이 실시간으로 업데이트됩니다.
* 끊김 없는 무한 스크롤: 아래로 내릴수록 새로운 밈이 계속해서 부드럽게 나타납니다.
* 로딩 최적화: 이미지가 뜨기 전까지 깔끔한 로딩 화면(스켈레톤)을 보여주어 시각적 완성도를 높였습니다.
* 플랫폼 식별: 각 밈이 어디서 온 것인지(유튜브, 틱톡 등) 아이콘으로 직관적으로 알 수 있습니다.
② 상세 화면 (Detail View)
* 몰입형 영상 재생: 유튜브 밈의 경우, 상세 화면 진입 시 영상과 소리가 즉시 재생됩니다.
* 원본 페이지 이동: 밈 원본 페이지로 이동합니다.
* 공유 : 재미있게 본 밈을 주변 사람들에게 공유합니다.


## 사용 기술 (Tech Stack)

* Frontend: Flutter (State Management: Riverpod)
* Backend: Supabase (PostgreSQL), Deno Edge Functions
* Design: Stitch, Figma


## 성능 최적화 및 적용 이유 

# 백그라운드 병렬 처리 (`Isolate` & `compute`)
* 이유: 메인 UI 스레드에서 대량의 JSON 파싱을 수행할 경우 발생하는 프레임 드랍(Jank)을 방지하기 위함.
* 효과: 무거운 연산을 별도 Isolate로 분리하여 스크롤 중에도 60fps 이상의 부드러움 유지.

# 계층적 캐싱 전략 (cacheExtent & CachedNetworkImage)
* 이유: 동일 이미지 반복 다운로드로 인한 데이터 소모를 막고 오프라인 열람 지원.
* 효과: 백그라운드 상태에서 이미지 사전 다운로드로 인한 부드러운 화면 전환 및 이미지 캐싱으로 인한 이미지 로드 api 2배 감소

# Supabase
* 이유: 물리적 서버를 구성하는 대신 수집 로직(크롤러)만 코드로 짜서 올리면 전 세계 엣지 네트워크에서 실행, 
       PostgreSQL기반 복잡한 필터링 및 데이터 무결성 최적화,사용자가 없을 때는 비용이 0원이며, 유지보수를 위한 인프라 관리 리소스가 전혀 들지 않음
* 효과: 서버리스 아키텍처를 채택함으로써 서버 관리 부담을 줄이고 이를 통해 확보한 리소스를 데이터 무결성 최적화와 초고속 렌더링에 투입하여, 운영 비용 0원으로 상용 서비스 수준의 퍼포먼스를 구현
